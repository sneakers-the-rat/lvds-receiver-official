# 3D models for board visualisation

This directory holds every 3D model the board's footprints
reference, mirrored into the repo so the website's 3D view (and any
GLB/STEP export) renders identically anywhere — no dependency on a
locally installed KiCad 3D library, which neither CI nor the fab
artefact pipeline carries. Library models are present as VRML;
where the headless exporter needs them, their STEP siblings are
mirrored too.

Layout mirrors the KiCad library tree (`<Library>.3dshapes/<file>`),
because the footprints reference models by paths under
`${KICAD6_3DMODEL_DIR}` / `${KICAD7_3DMODEL_DIR}` /
`${KICAD8_3DMODEL_DIR}`. Point all three variables at this directory
and every reference resolves. `scripts/make_fab.sh` does exactly
that when it exports `hw/fab/board-3d.glb`.

## Provenance

- Most files are unmodified copies from the KiCad packages3D
  library (fetched 2026-11-10 from the github.com/KiCad mirror,
  tree b8b3cfdf). KiCad library data is licensed CC-BY-SA 4.0 with
  the KiCad library exception; see the license header inside each
  file. One substitution: the board references
  `QFN-16-1EP_3x3mm_P0.5mm_EP1.45x1.45mm.wrl`, which the library no
  longer ships; the copy here is the same package with the 1.8 mm
  exposed pad (underside only, invisible in normal views).
- Five models (each as VRML + STEP) are simplified project-authored
  stand-ins for library models the current library no longer ships
  under the referenced names (Amphenol SMA and USB-C connectors,
  1812 fuse, Abracon ASE oscillator, Murata DFE201610P), written to
  the referenced paths.
- `pdlvds/` holds project-authored models for this design's own
  custom footprints (WE-FLEX HV transformer, Harwin shield can and
  clips, C30737 APD, S8664 APD, SMT740 LED), bound to a throwaway
  copy of the board at render time by `scripts/attach_models.py`;
  the shipped board file is never modified for rendering.

All project-authored models are generated by
`scripts/gen_models3d.py` — edit dimensions there, not in the .wrl
files. They are visualisation solids at the real parts' datasheet
dimensions, not mechanical models; the board's STEP export remains
the mechanical record.
